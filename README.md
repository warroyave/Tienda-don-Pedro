Tienda Don Pedro es un programa sencillo que simula una tienda de barrio, orientado a gestionar productos, clientes frecuentes y ventas.

## 🚀 Ejecución del programa

Para iniciar el programa, ejecuta el siguiente comando desde la raíz del proyecto:

•⁠  ⁠⁠ python src/main.py ⁠

## 📁 Archivos de datos

El programa utiliza los siguientes archivos de texto para almacenar la información:

•⁠  ⁠⁠ productos.txt ⁠: contiene los productos disponibles y sus precios.
•⁠  ⁠⁠ clientes.txt ⁠: almacena la información de los clientes frecuentes.
•⁠  ⁠⁠ ventas.txt ⁠: registra las ventas realizadas.
